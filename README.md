**ArezOS** is a simple, ready-to-use Arch Linux distribution designed specifically for everyday users. Built on the powerful and flexible foundation of Arch Linux, ArezOS eliminates the steep learning curve and provides a complete desktop experience out of the box. 

Our philosophy is simple: **We build for people, not for profit.**

##  Key Features

*   **Arch Linux Base:** Enjoy the latest software, rolling releases, and access to the vast AUR (Arch User Repository) without the complex manual setup process.
*   **User-Friendly Installer:** Comes with the widely trusted **Calamares** graphical installer. Installing ArezOS is fast, intuitive, and accessible even for those who have never used Linux before.
*   **KDE Plasma Desktop:** ArezOS features the modern, beautiful, and highly customizable KDE Plasma environment. It provides a feature-rich, familiar, and productive workspace right from the first boot.
*   **Ready Out of the Box:** No need to spend hours configuring your system. ArezOS comes pre-packed with all the essential software, drivers, and utilities required for daily work, browsing, and multimedia.

##  Who is this for?

ArezOS is perfect for:
*   Users who want the performance and freshness of Arch Linux but prefer a simple, graphical installation process.
*   People looking for a complete, feature-rich desktop environment (KDE Plasma) without the hassle of manual configuration.
*   Anyone who values a system that is ready to work immediately after installation.

##  Installation

ArezOS uses the **Calamares** installer. You can simply boot from the Live ISO, follow the on-screen instructions, and have your system fully installed on your hard drive in just a few minutes. No terminal commands required for the base setup.
